# 上新图 Industry 项目方案

## 1. 项目定位

上新图 Industry 是面向中小制造企业、工业品供应商和工厂销售人员的工业品智能上新 Agent。它把产品照片、铭牌、规格参数和说明书转化为可审核、可追溯、可直接发布的产品主图、参数卡、卖点图和渠道资料包。

项目参加微信小程序开发赛项，选择“AI赋能产业服务”方向，同时作为团队的工业软件作品集项目。

## 2. 要解决的问题

中小制造企业的产品资料经常分散在 Excel、PDF、照片和员工经验中。新品发布需要反复抠图、复制参数、编写介绍和检查版本，容易出现型号、尺寸、材质和图片不一致的问题。

本项目重点解决：

- 工业品照片处理与标准化排版；
- 产品主数据、SKU和规格参数的结构化管理；
- 说明书与技术文档的知识库检索；
- 多渠道产品资料的自动生成；
- 关键参数的来源标注、冲突检测和人工确认；
- AI任务的过程记录、失败回退和结果追溯。

## 3. 核心流程

```text
拍摄或上传产品照片
  → 扫码/选择 SKU
  → 上传参数表或说明书
  → OCR 与多模态识别
  → RAG 检索企业知识库
  → Agent 调用图片、文案与校验工具
  → 生成主图、参数卡、卖点图和产品介绍
  → 参数一致性检查
  → 人工确认并导出资料包
```

## 4. 功能范围

### 已有 MVP

- 微信原生小程序和 Node.js API；
- PNG/JPEG 上传；
- 原图、AI抠图、AI商业场景三种处理方式；
- 三套模板、两种比例、三类营销图片；
- 本地草稿、作品库、保存相册和再次编辑；
- AI结果缓存、任务持久化、能力预检和基础限流；
- 自动化测试。

### 比赛核心版本（P0）

- 微信登录与团队工作空间；
- 产品、SKU、规格参数和素材数据库；
- 工业品铭牌 OCR 与人工校正；
- PDF说明书上传、切分、向量检索与来源引用；
- 工业品上新 Agent 工具编排；
- 工业风主图、参数卡和企业品牌模板；
- 关键参数防幻觉与冲突提醒；
- 生成任务进度、审核记录和资料包导出。

### 增强版本（P1）

- Excel 批量导入产品资料；
- 小程序扫码查找 SKU；
- 企业品牌规范库；
- 多渠道尺寸与文案适配；
- 订阅消息通知异步任务完成；
- 简单的数据统计看板。

### 展示性扩展（P2）

- ERP/PIM 模拟连接器；
- 多租户与角色权限；
- 产品资料版本对比；
- 成本、延迟和AI质量评测；
- 脱敏企业试点案例。

## 5. 数据模型建议

- `organizations`：企业/团队；
- `users`、`memberships`：用户、角色和企业关系；
- `products`、`skus`：产品主数据和SKU；
- `spec_definitions`、`sku_spec_values`：规格定义和值；
- `assets`：原图、抠图、场景图和成片；
- `documents`、`document_chunks`：说明书及知识库分块；
- `generation_jobs`：异步生成任务；
- `agent_runs`、`tool_calls`：Agent运行与工具调用；
- `parameter_evidence`：参数来源与置信度；
- `reviews`、`audit_logs`：人工审核和审计记录；
- `export_packages`：导出资料包。

关键规格字段不得只保存在大模型生成文本中，必须有结构化值、来源和审核状态。

## 6. 技术方案

- 小程序：微信原生框架；
- API：Node.js；
- 数据库：PostgreSQL；
- 对象存储：兼容 S3/OSS 的存储服务；
- AI：大语言模型、多模态识别、图像生成；
- RAG：文档解析、向量化、混合检索和来源引用；
- Agent：受控工具调用，不允许模型直接修改关键参数；
- 可靠性：异步任务、幂等、缓存、限流、超时、重试与降级；
- 安全：鉴权、企业数据隔离、最小权限、日志脱敏和密钥后端托管。

## 7. 团队分工

### 产品负责人 / AI与集成

- 业务流程、Agent设计、模型接入和系统集成；
- GitHub维护、PR审查、演示与答辩。

### 小程序 / UI

- 使用 Stitch 设计页面；
- 完成产品录入、任务进度、结果预览和作品管理；
- 负责手机适配与真机体验。

### 数据库 / 后端

- 数据库ER图、迁移和API；
- 登录、数据隔离、任务日志和自动化测试。

### 指导老师

- 审核工业数据模型和企业流程；
- 提供真实需求与脱敏案例；
- 指导ERP/PIM对接和企业试点。

## 8. 里程碑

### M1：工程开源与协作基线

- 建立仓库、Issue、分支和PR流程；
- 所有人完成本地启动与一次文档PR。

### M2：工业数据底座

- 完成登录、企业空间、产品/SKU/规格数据库；
- 支持产品录入、查询与编辑。

### M3：知识库与Agent闭环

- 支持说明书入库、检索与引用；
- Agent完成识别、检索、生成、校验和导出流程。

### M4：比赛完成度

- 完成UI、真机测试、错误处理和性能优化；
- 准备演示数据、录屏、答辩材料和源代码包。

### M5：企业验证与作品集

- 邀请至少一名真实目标用户试用；
- 记录前后耗时、准确率和修改次数；
- 整理架构图、ER图、测试报告与项目复盘。

## 9. 验收指标

- 一次完整上新任务可以在小程序中闭环完成；
- 关键参数均可看到来源和审核状态；
- AI不可用时仍能使用基础模板完成制作；
- 不同企业之间数据严格隔离；
- 自动测试、微信开发者工具编译和关键真机流程通过；
- 使用脱敏样例证明项目确实降低资料制作时间。

## 10. 演示案例

选择一个传感器、轴承、五金零件或小型设备作为样例：上传产品照片和PDF说明书，扫描/填写型号，系统识别铭牌并检索参数，Agent生成三张工业品图片与产品介绍；当数据库与说明书参数不一致时给出冲突提示，人工确认后导出完整资料包。
