# 上新图 Industry

> 面向中小制造企业的工业品智能上新 Agent。

项目当前从“小商家商品作图 MVP”升级为“工业品智能上新与资料发布助手”。目标是把产品照片、铭牌、规格参数和说明书转化为可审核、可追溯的产品主图、参数卡、卖点图与渠道资料包。

当前代码已实现原图上传、可选的 remove.bg AI 商品抠图、可选的阿里云百炼 `wan2.6-image` AI 商业场景生成、Canvas 三张模板排版、PNG 预览、保存相册与本机作品库。工业产品数据库、RAG知识库、Agent编排、登录和云端部署属于下一阶段，尚未实现。

完整产品与开发方案见 [docs/PROJECT_PLAN.md](docs/PROJECT_PLAN.md)，协作规则见 [CONTRIBUTING.md](CONTRIBUTING.md)。

## 为什么前后端分开

- `frontend/` 是微信原生小程序，只处理界面、用户输入和页面跳转。
- `backend/` 是独立 Node.js API，负责校验业务请求、模板数据与生成任务。
- 两端通过 HTTP + JSON 通信。以后换成网页/App，或更换 AI 服务商，都不必重写全部代码。

## 本地运行

后端（需要 Node.js 20.6+；当前电脑已安装 Node.js 24）：

```powershell
cd backend
npm.cmd start
```

首次使用 AI 抠图：在 remove.bg 官方控制台创建 API Key，把 `backend/.env.example` 复制为 `backend/.env`，只替换其中的密钥，然后重新启动后端。`.env` 已被 Git 忽略，不要把密钥发到聊天、截图或提交到仓库。未配置密钥时，可在模板页选择“保留原始照片”继续使用原有排版。

电脑浏览器访问 `http://127.0.0.1:3001/health`。真机联调时，手机和电脑需在同一可信 Wi-Fi，使用电脑当前 WLAN IPv4 地址访问 `http://<电脑局域网IP>:3001/health`，应看到 `{"status":"ok"}`。

端口约定：另一个小程序后端使用 `3000`；本项目“上新图”固定使用 `3001`。两个项目分别在各自终端启动，可以同时运行。若看到 `EADDRINUSE: 3001`，说明已有进程占用了本项目端口，不要改回 `3000`，先停止重复启动的“上新图”后端。

后端开发模式监听局域网地址；仅在可信 Wi-Fi 中启动，Windows 防火墙提示只允许专用网络。局域网 IP 可能在换 Wi-Fi 或重连后变化：运行 `ipconfig` 查找带默认网关的 WLAN IPv4，并同步修改 `frontend/services/api.js`。这不是上线地址，正式发布必须换成已备案的 HTTPS 域名和有鉴权的后端。

## AI 商品场景生成

模板页已接入阿里云百炼万相 `wan2.6-image` 的参考图生图流程，可选择高级影棚、生活方式、质感暗调和清新色块。后端异步创建任务、轮询结果，并立即把临时结果保存到本地；重复的原图、场景和比例会复用缓存。

1. 复制 `backend/.env.example` 为 `backend/.env`。
2. 在阿里云百炼北京地域取得 API Key，填写 `DASHSCOPE_API_KEY`。默认使用官方共享北京地址，不需要业务空间 ID；不要提交或把密钥发到聊天中。
3. 重新启动本项目后端，再访问 `http://127.0.0.1:3001/api/capabilities`，确认 `aiScene.available` 为 `true`。

真实调用可能产生模型费用。当前每次只生成一张 AI 场景底图，再由小程序排版三种用途以控制成本。生成模型仍可能改变商品细节，因此每张成片必须人工核对颜色、形状、数量、包装文字与 Logo；不合格图片不要用于销售。

前端：打开微信开发者工具，导入 `frontend` 目录，AppID 可先使用测试号。开发阶段要在“详情 → 本地设置”中勾选“不校验合法域名”，然后编译。

## 当前接口

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/health` | 判断后端是否存活 |
| GET | `/api/templates` | 获取模板列表 |
| GET | `/api/capabilities` | 获取 AI 是否可用、限制和安全的汇总统计，不返回密钥 |
| POST | `/api/images` | 上传 PNG/JPEG 原始二进制，最大 5MB，返回图片 ID |
| GET | `/api/images/:id` | 读取上传原图 |
| POST | `/api/images/:id/remove-background` | 调用 remove.bg 移除背景并保存透明 PNG |
| POST | `/api/images/:id/generate-scene` | 调用百炼 `wan2.6-image` 生成商业场景底图，成功后立即下载到本地 |
| POST | `/api/generations` | 校验原图与商品信息，返回客户端排版配置 |
| GET | `/api/generations?limit=20` | 查询最近的后端生成任务，最多 50 条 |
| GET | `/api/generations/:id` | 查询某次生成任务 |

生成任务会持久化到 `backend/data/generations.json`，最多保留最近 200 条，重启后端不会丢失。AI 结果按原图内容哈希缓存到 `backend/data/ai-state.json`：抠图按原图缓存，场景图按“原图 + 场景 + 比例”缓存；同一输入再次处理且结果文件仍存在时直接复用，不重复调用外部接口。每个来源默认每小时最多发起 10 次未缓存的 AI 请求，用于防止误操作消耗额度。

更多学习说明见 [docs/LEARNING_GUIDE.md](docs/LEARNING_GUIDE.md)。

## 首次验收清单

1. 启动后端并导入前端，点击首页开始制作；应进入上传页。
2. 不选图片、不填名称直接下一步；应提示补全信息。选择自己的图片，填写名称和价格 `1.234`；应提示最多两位小数。
3. 改成 `19.90`，输入一个卖点但不点“添加”，进入下一步；卖点图应带上这个卖点。
4. 选择模板、比例并点“制作 3 张商品图”；应先上传后排版，切换三种用途应看到不同 PNG。主图/促销图包含价格，卖点图包含卖点。分别试 1:1、3:4，保存图尺寸应为 1080×1080、1080×1440。换模板后底色、文字颜色应变化；商品原片不裁切、不拉伸，原背景仍在。
5. 返回模板页，停止后端再创建；应显示失败提示并停留原页，按钮恢复可用。重新启动后端后可重试。
6. 在真机点击保存，授权后相册应出现当前选中的一张图；点“保存整套”应顺序保存三张并显示进度。拒绝权限时应显示失败及设置入口，不能提示保存成功；授权后再次保存。
7. 点击修改商品文字/价格，应回到保留输入的上传页，修改后重新制作，成片显示新值。尝试长名称、三条卖点、横图/竖图，检查不重叠、不变形。

失败时请提供：操作步骤、页面现象和开发者工具控制台错误文字。不要发送密钥。

助手自动检查：在 `backend/` 执行 `npm test`，包含接口集成测试和模拟微信 API 的页面逻辑测试；不等于微信编译、视觉或真机测试通过。

## 草稿与作品库

- 上传页会把商品名称、价格、卖点和已选图片保存为本机草稿，再次进入可继续填写。
- 成片页点击“收藏整套”后，三张 PNG 会进入底部导航的“作品”。作品库最多保留 6 套，超过后自动清理最早一套。
- 作品只保存在当前微信/开发者工具环境，不会上传账号云端，也不会跨设备同步。清理微信数据、删除小程序或重装开发者工具可能导致作品丢失。
- 成片页可以保存当前图片或顺序保存整套三张；中途失败会显示已成功保存的数量。作品库可点击三图拼贴查看整套大图，也可保存主图或整套。
- 新收藏的作品会保留原图路径、AI 处理标记、促销文案和制作时间，可从作品库点“再次编辑”复用商品信息；旧版本作品没有原图路径时需要重新选图。
- 删除作品会删除该套三张本地文件且无法恢复。

## 当前三种模板与三种用途

- 暖调生活志：奶油纸感、陶土色、错位色块，适合手作、食品、家居等温暖风格。
- 极简编辑部：深色侧栏、浅灰网格和杂志式留白，适合需要克制、清晰信息层级的商品。
- 新季促销场：高对比橙红、黄色强调、大价格区和行动按钮，适合活动宣传。
- 商品主图采用大图与名称/价格；卖点图采用照片与编号卖点分栏；促销图采用图文错位、大价格与行动按钮。选择“智能抠出商品”时先移除原背景，再把透明主体融入模板并增加柔和阴影；选择“保留原始照片”时维持原图。
- 上传页可自定义最多 12 字的促销按钮文案；模板页可选择“完整、突出、特写”三档商品大小。AI 抠图后，成片页可在原始照片和透明主体之间切换对比。
- 可填写最多 12 字的品牌名称并选择五种品牌色，品牌标识会绘制到三张成片。商品还可用九宫格调整位置；模板、比例、商品大小、位置和 AI/原图模式会自动记住，下一次制作无需重新选择。
- 首页会显示未完成草稿和最近一套作品，可快速继续填写或查看最近三张成片。

## 本地存储和使用边界

- 开发后端监听 `0.0.0.0:3001`，用于同一可信 Wi-Fi 的真机联调；正式上线仍需 HTTPS 域名、鉴权、限流和正确的防火墙策略，不能把当前开发服务直接暴露到公网。
- 模板页会先读取后端能力：没有配置 `REMOVE_BG_API_KEY` 时自动使用原图模式并显示原因；不会先上传、等待后才报错。能力接口只返回布尔状态和汇总计数，不会返回密钥。
- 原图与 AI 结果都保存在 `backend/data/uploads/`，服务重启后仍在；当前没有自动过期清理，不要上传敏感客户资料。排版任务已持久化到 `backend/data/generations.json`（最近 200 条），重启不再丢失。PNG 成片是微信临时文件，需保存到相册，或点“收藏整套”进入本机作品库（最多 6 套）；作品库只存在当前设备，清理微信数据会丢失。
- 后端只有大小与文件签名校验，并非完整图片解码或病毒扫描；没有用户鉴权、访问隔离、总存储配额或限流，不可直接部署公网。正式上线前需要补齐这些能力与图片删除/保留策略。
- 只有点击“制作”才上传原图；选图本身不上传。失败后重试可能保存重复原图，当前没有去重。上传目录已加入 `.gitignore`。
- 部分手机照片可能是 HEIC 等格式，当前仅支持 PNG/JPEG；不支持时换图。真机还需验收相册权限、隐私授权、照片方向和字体渲染。
